# STEB's - AI Operations Brain

## User Guide

Welcome to **STEB's** - your intelligent e-commerce operations analysis platform. This guide will help you get started with using the application.

---

## 🚀 Getting Started

### What is STEB's?

STEB's is an AI-powered platform that analyzes your e-commerce operations data to provide insights about:
- **Sales & Revenue** - Track sales performance, identify revenue drops, and understand trends
- **Inventory & Supply** - Monitor stock levels and identify supply chain issues
- **Marketing & Campaigns** - Analyze campaign performance and marketing effectiveness
- **Customer Support** - Track customer complaints, refunds, and support metrics

---

## 📱 Navigation

### Home Page (Dashboard)
The home page displays your analytics dashboard with:
- **Statistics Cards** - Quick overview of total analyses, success rate, and average processing time
- **Charts & Graphs** - Visual representation of job statuses and trends
- **Agent Performance** - See how different AI agents are performing
- **System Health** - Monitor the status of backend services
- **Recent Analyses** - List of your most recent analysis jobs

### Agent Page (Chat Interface)
The agent page is where you interact with the AI:
- **Category Cards** - When starting a new session, select from Sales, Inventory, Marketing, or Support categories
- **Predefined Questions** - Each category has common questions you can select
- **Chat Input** - Type your own custom questions
- **Real-time Progress** - See the analysis progress as it happens

---

## 💬 How to Use the AI Agent

### Starting a Conversation

1. Navigate to the **Agent** page using the navigation bar
2. You'll see four category cards:
   - 💰 **Sales & Revenue** - Questions about sales performance
   - 📦 **Inventory & Supply** - Questions about stock and supply
   - 📢 **Marketing & Campaigns** - Questions about marketing
   - 🎧 **Customer Support** - Questions about customer issues

3. Click on a category to see predefined questions
4. Select a question or type your own in the input box
5. Press **Enter** or click the send button

### During Analysis

When you submit a question:
- You'll see a "Query Submitted" badge
- An animated loading indicator shows the analysis is in progress
- The AI processes your question through multiple specialized agents

### Stopping an Analysis

If you need to cancel an ongoing analysis:
- Click the **Stop** button that appears in the input area during processing
- The analysis will be cancelled and you can start a new one

### Viewing Results

Once the analysis is complete:
- The AI will display a comprehensive analysis including:
  - Summary of findings
  - Root cause analysis
  - Detailed findings from each agent
  - Recommendations

## 🎨 Customizing Your Experience

### Theme Options

STEB's offers three distinct UI themes:

1. **STEB's (Default)** - Modern purple/indigo theme
2. **Claude** - Warm orange/brown tones
3. **Twitter** - Clean blue theme similar to Twitter/X

### Dark/Light Mode

Toggle between dark and light mode using the sun/moon button (☀️/🌙) in the navigation bar.

### Switching Themes

1. Find the **UI** dropdown in the navigation bar
2. Select your preferred theme: STEB's, Claude, or Twitter
3. The change is applied immediately and saved to your browser

---

## 🔄 Session Management

### Refreshing a Session

To start a fresh conversation:
1. Click the **Refresh** button (🔄) in the navigation bar
2. Confirm that you want to clear the current session
3. All chat history will be cleared

**Note:** Chat history is stored only for the current session. Refreshing the page or closing the browser will also clear the history.

## 📊 Understanding the Dashboard

### Statistics Cards

| Card | Description |
|------|-------------|
| Total Analyses | Total number of analyses performed |
| Last 24 Hours | Analyses submitted in the last day |
| Success Rate | Percentage of successful analyses |
| Avg. Time | Average time to complete an analysis |

### Job Status Chart

Shows the distribution of jobs by status:
- 🟢 **Completed** - Successfully finished
- 🔵 **Running** - Currently processing
- 🟡 **Pending** - Waiting to start
- 🔴 **Failed** - Encountered an error
- 🟣 **Cancelled** - Stopped by user

### System Health

Monitor the status of backend services:
- 🟢 **Healthy** - Service is operational
- 🟡 **Degraded** - Service has issues but working
- 🔴 **Unhealthy** - Service is down
- ⚪ **Unknown** - Status cannot be determined

## ❓ Frequently Asked Questions

### Why is my analysis taking a long time?

The AI processes your question through multiple specialized agents. Complex questions may take longer. You can monitor progress in the chat interface.

### Can I ask custom questions?

Yes! While predefined questions are available for convenience, you can type any question related to your e-commerce operations.

### Why did I get an error message?

Errors can occur due to:
- Network issues
- Backend service problems
- Invalid question format

Try rephrasing your question or checking if the system is healthy on the dashboard.

### Is my data saved?

- Chat history is only stored for the current browser session
- Analysis results are stored on the backend for a limited time (typically 24 hours)

## 🆘 Getting Help

If you encounter issues:
1. Check the System Health on the dashboard
2. Try refreshing your browser
3. Clear your session and start fresh
4. Contact your system administrator
